# Baddie.B Showroom (demo)

ม็อกอัพหน้าร้านแบบ "ราวแขวน 4 ราวล้อมตัว" ทดลองเท่านั้น ไม่เชื่อมกับร้านจริง (baddie-b) ปุ่มใส่ตะกร้าแค่นับเลข

- เปิดดู: `index.html` (เปิด GitHub Pages: Settings → Pages → Branch `main` / root แล้วจะได้ลิงก์ `https://markpaytai.github.io/-baddie-b-showroom-demo/`)
- ปัด / ลากซ้าย–ขวา = เดินดูราว · แตะเสื้อผ้า = หยิบออกมา · แตะซ้ำหรือ "ดูสินค้า" = หน้าสินค้า

## ไฟล์
| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `index.html` | หน้าโชว์รูมทั้งหมด (ตั้งค่าระยะห่างราว `SPREAD` และความโค้ง `CURVE` ได้ที่ต้นสคริปต์) |
| `products.js` | รายการสินค้า: รหัส ชื่อ หมวด ราคา ไซส์ สี ไซส์ชาร์ต และรูป |
| `img/<รหัสสินค้า>.webp` | รูปเสื้อผ้าบนราว 1 ไฟล์ต่อ 1 สินค้า |
| `old/chatgpt-version.html` | เวอร์ชันแรกที่ ChatGPT ทำไว้ |

## แต่งรูป / เปลี่ยนรูป
- เปลี่ยนรูป = เอารูปใหม่มาทับไฟล์เดิมใน `img/` **ชื่อเดิม** (เช่น `img/JKT-0001.webp`) หรือแก้ช่อง `"img"` ใน `products.js` ให้ชี้ไปไฟล์ใหม่ (`.png` ก็ได้)
- รูปที่ดีที่สุด: **พื้นหลังโปร่งใส** (PNG / WebP), เสื้อผ้าหันหน้าตรง แขวนตรง ไม้แขวนอยู่ด้านบน, ครอปชิดตัวเสื้อผ้า ไม่เว้นขอบ, กว้างประมาณ 400–800 px
- หน้าเว็บอ่านสัดส่วนรูปเอง รูปสูงหรือเตี้ยแค่ไหนก็แขวนได้
- เพิ่มสินค้า = เพิ่มรายการใน `products.js` (หมวด `category` ต้องเป็น Jackets / Tops / Jeans / Pants / Dresses)
